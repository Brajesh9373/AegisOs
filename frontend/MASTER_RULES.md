UI Change Policy

There are only three allowed UI operations:

1. Visual Refresh
   Improve colors, spacing, typography, icons and styling.
   Business layout must remain unchanged.

2. Enhancement
   Add missing business features without moving existing functionality.

3. Refactor
   Extract reusable components without changing UI behavior.

A page redesign is NEVER allowed unless explicitly requested.

If a redesign is required, it must be approved first.
