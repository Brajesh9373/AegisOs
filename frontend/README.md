# aegisOS Enterprise Platform

aegisOS is an Enterprise AI OS enabling autonomous digital employees, governed by strict RBAC and Zero Trust architecture.

## Getting Started

1. Copy `.env.example` to `.env`
2. Run `docker compose up -d`
3. Access Web UI at `http://localhost:5173`
4. Access API at `http://localhost:3001`

For more details, see [Development Guide](docs/DEVELOPMENT.md).
