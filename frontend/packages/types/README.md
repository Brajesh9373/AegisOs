# @aegis/types

The fundamental type system foundation for aegisOS. Provides standard, completely pure type utilities used universally across the monorepo. This package contains absolutely zero runtime execution logic.

## Principles

- **Purity**: Zero runtime code.
- **Independence**: Zero dependencies.
- **Safety**: Strict adherence to TypeScript standard utilities.
- **Strictness**: Total ban on implicit/explicit `any`.

For comprehensive constraints and boundaries, see [ARCHITECTURE.md](./ARCHITECTURE.md).
